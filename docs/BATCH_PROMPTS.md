# 15 готовых промптов для ChatGPT (по 9 подарков на лист)

**Порядок работы для каждого листа:** 1) вставьте промпт, 2) скачайте картинку, 3) выполните команду под промптом (id идут по порядку слева направо, сверху вниз).
Первым сообщением в НОВОМ чате отправьте стиль (раздел «Часть 1» из `DESIGN_PROMPT.md`), потом по очереди все листы в том же чате — стиль будет единым.
Если ChatGPT нарисовал лист не 3×3 или поменял порядок — попросите «перегенерируй строго 3×3, одинаковые отступы, фон однотонный белый».
